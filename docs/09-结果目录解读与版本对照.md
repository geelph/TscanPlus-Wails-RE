## 4. 版本对照：3.5.5 vs 3.5.6

本仓库的结果是 **v3.5.5** 产出的。换成 **v3.5.6** 全量复测后，结论是：**三套加密一个都不用改。**

| 项 | v3.5.5 | v3.5.6 | 结论 |
|---|---|---|---|
| exe 大小 | 137,507,640 B | 137,971,512 B | 变化（代码 +464 KB） |
| sha256 | —（样本已替换） | `0A29C647EA1C0FEAC9C63DA77FDE6D00F6814E9083B999913FD8A6D9FE0F0C2E` | — |
| Go / Wails / 模块 | go1.25.10 / v2 / `TscanGui` | 同左 | 不变 |
| embed 表 / 文件 | 23 / 9597 | 23 / 9597 | 不变 |
| **POC 口令** | `Fb4F@…RD7` + SHA-256 | 同一个口令，**9060/9060 成功** | ✅ 未失效 |
| POC 明文总量 | 14,587,469 B | 14,587,495 B（+26 B） | 只有 **1 条** POC 内容更新（`UNA-CMS-14.0.0-RC-…`，3184→3210 B） |
| **指纹库** | 4,250,752 B → 3,188,052 B / 22003 条 | 密文与明文**完全相同** | ✅ 未失效 |
| **前端 `.enc`** | 5 个 | 5 个，与 3.5.5 **逐字节相同**（sha256 一致） | ✅ 未失效 |
| 前端 bundle | `index.b800a9f7.js` 4,834,884 B | `index.3227ff1c.js` 4,863,895 B | 重新构建（key 逻辑不变） |
| ReWails 统计 | 14508 函数 / 5951 精确签名 / 1989 类型 | 14880 / 5997 / 2003 / 322 依赖 | 代码有增量 |

复测命令（三步，全部 `✓` 即说明"没失效"）：

```bash
python tools/goembed_extract.py samples/TscanPlus_Win_Amd64.exe -o out --oneclick
python tools/decrypt_all.py --root out --force
# => [✓] pocs 解密 9060 / 失败 0 ；technologies 3,188,052 B / 22003 条 ；5 个 .enc 全解
```

### 结论怎么用

* **想用最新版**：直接按 [docs/08](08-完整复现手册.md) 跑一遍，用 v3.5.6 出的树会与本仓库的 `output/` 相差 1 个 POC 文件 + 前端 bundle 哈希名。
* **补丁/偏移类**（DevTools 补丁、Frida Hook 偏移）**与版本强相关**：`file+0x2630474` / `0x1a4cc40` 是 3.5.5 的地址，3.5.6 要重新按函数名定位（`wails_devtools_patch.py` 本来就是按 `pclntab` 名字找的，会自动适配；Frida 的 `--offset` 需要手工换）。
* **加密格式**是跨版本稳定的：真变了的话，`decrypt_all.py` 会以"失败 N 条"的方式立刻告诉你，而不是静默出错。
