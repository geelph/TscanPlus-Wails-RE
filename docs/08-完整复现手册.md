# 08 · 完整复现手册（从下载样本到全量产物）

照这个顺序走，每步都有**可对照的期望值**；数字不对就停下来看"排错"一节。

环境：Windows 10/11（本项目的实测环境）或 Linux/macOS；Python ≥ 3.10。

---

## 0. 准备

```bash
# 取样本（本仓库不分发二进制）
#   https://github.com/TideSec/TscanPlus/releases/download/v3.5.6/TscanPlus_Win_Amd64.zip
# 或直接去 releases 页挑版本： https://github.com/TideSec/TscanPlus/releases
unzip TscanPlus_Win_Amd64.zip -d samples/

# 依赖
pip install -r tools/requirements.txt        # 至少需要 cryptography

# 目录约定（后文都按这个写）
#   samples/   样本 exe
#   out/       中间产物
```

可选：想在真实运行的程序里核对接口，装 `frida-tools`。

## 4. 校验（这一步别省）

```bash
# ① 条数
ls out/pocs.decrypted/**/*.yaml | wc -l          # 9060

# ② YAML 可解析 + id 唯一性
python - <<'PY'
import yaml, pathlib, collections
c = collections.Counter()
for p in pathlib.Path('out/pocs.decrypted').rglob('*.yaml'):
    c[yaml.safe_load(p.read_text(encoding='utf-8'))['id']] += 1
print(sum(c.values()), 'files /', len(c), 'unique ids')
PY
# => 9060 files / 9059 unique ids   （厂商自己写重了 1 条）

# ③ 指纹库
python -c "import json;d=json.load(open('out/technologies.json.decrypted',encoding='utf-8'));\
print(len(d['technologies']),'fingerprints /',len(d['categories']),'categories')"
# => 22003 fingerprints / 14 categories

# ④ 前端 JSON
python -c "import json;print([len(json.load(open(f'out/frontend/dist/assets/{n}',encoding='utf-8'))) \
for n in ['webPayloads.json','toolCommands.json','intranetPayloads.json','navigation.json','toolNavigation.json']])"
# => [705, 378, 85, 2, 21]
```

## 7. 排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `-l` 报"没找到 embed.FS 表" | 样本被 garble 改造过 / 不是 Go 程序 | 先看 buildinfo；加 `-v` 看候选命中详情 |
| 表数量对得上，但文件全是乱码 | 正常 —— 加密资源本来就是高熵 | 走第 3 步解密 |
| POC 全部 `fail`，错误 `InvalidTag` | 口令换了 | `frida_capture_poc_key.py` 重新抓 key |
| POC 全部 `fail`，错误 `密文过短` | 混淆 `KnpClZd2` 变了 | 重新分析该函数，改 `unshift()` |
| `.enc` 解不开（所有候选 key 失败） | key 不在 JS 里 / 派生逻辑变了 | `--key` 手工给；或看 JS 里 `importKey` 附近 |
| `technologies.json` 解出来不是 JSON | CBC 的 IV 惯例变了 | 看 `conf.Ahm4CSOj8Knikz7`；工具已兼容 `iv=key` 与 `iv=head16` |
| `decrypt_all.py` 在 Windows 控制台打印 `UnicodeEncodeError` | 老控制台是 GBK | 工具内已强制 UTF-8；如仍报错，`chcp 65001` 或用 Windows Terminal |
| `pip install cryptography` 失败 | 无预编译轮子 / 网络 | 换 Python 3.11+，或 `pip install --only-binary :all: cryptography` |
