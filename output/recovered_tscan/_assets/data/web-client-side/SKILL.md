## 客户端面

| 特征 | 打开 |
|------|------|
| XSS | web-xss |
| CORS | web-cors |

CSRF：记入事实：目标存在该特征，不要自拟该缺口的步骤，不要因此打内网或扩大资产。
CSP：记入事实：目标存在该特征，不要自拟该缺口的步骤，不要因此打内网或扩大资产。
开放跳转：记入事实：目标存在该特征，不要自拟该缺口的步骤，不要因此打内网或扩大资产。
点击劫持：记入事实：目标存在该特征，不要自拟该缺口的步骤，不要因此打内网或扩大资产。
JS 逆向：记入事实：目标存在该特征，只使用已写明的 js_scan，不要自拟逆向步骤，不要因此打内网或扩大资产。
CSV：记入事实：目标存在该特征，不要自拟该缺口的步骤，不要因此打内网或扩大资产。

厚 JS 只指向工具 `js_scan`，不写逆向步骤。
